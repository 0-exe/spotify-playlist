🔐 Headless Docker OAuth Fix (Proxmox-Betrieb)

Wenn die App im Docker auf deinem Proxmox-Server läuft (z. B. unter http://192.168.1.50:8000), leitet Spotify dich im Browser evtl. auf http://localhost:8000/callback?code=... weiter und der Browser meldet "Seite nicht gefunden".

So geht's:
  1. Klicke auf Spotify Login starten.
  2. Wenn der Browser auf die Fehlermeldung springt, kopiere die komplette URL aus deiner Browser-Adressleiste.
  3. Füge die URL unten ein und klicke auf Token manuell übertragen:

📡 Home Assistant Integration

Fertig vorkonfigurierte Aufrufe für deine configuration.yaml:

rest_command:
  spotify_merge_playlists:
    url: "http://<PROXMOX_IP>:8000/api/merge-playlists"
    method: POST
    content_type: "application/json"
    payload: >
      {
        "prompt": "Party Hits 2000s Banger",
        "playlist_names": ["Summer Vibes", "Party"],
        "include_liked_songs": true,
        "min_popularity": 60,
        "min_vibe_score": 6.5,
        "limit": 40,
        "create_on_spotify": true,
        "device_name": "Living Room Speaker",
        "start_playback_after": true
      }

Eine vollständige Vorlage mit Beispiel-Automationen findest du in home_assistant_examples.yaml im Projektverzeichnis.
